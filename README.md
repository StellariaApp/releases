# Stellaria · Descargas

Instaladores públicos de las apps de Stellaria. El código de cada app vive en su propio
repositorio privado; aquí solo se publican los binarios.

Cada release lleva el nombre de la app delante de la versión:

| App | Tag | Ejemplo |
|---|---|---|
| Visage | `visage-vX.Y.Z` | `visage-v0.1.0` |
| Vela (agente) | `vela-agent-vX.Y.Z` | `vela-agent-v1.0.0` |

Enlace directo a un archivo:

```
https://github.com/StellariaApp/releases/releases/download/<tag>/<archivo>
```
